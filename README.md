# Social Media App

A simple social media app built using **React.js**.

## Features

- Create & Delete Posts
- Fetch Posts using API
- React Router
- Context API
- useReducer
- Loaders & Actions
- Bootstrap UI

## Tech Stack

- React.js
- JavaScript
- React Router DOM
- Bootstrap
- Vite
- DummyJSON API

## Run Locally

```bash
npm install
npm run dev
```

## Future Updates

Backend with **Node.js, Express.js & MongoDB** will be added in future versions.
